Frequently asked questions
How long should a meta title be?
Aim for 50–60 characters. Longer titles may be cut off in Google search results.
How long should a meta description be?
Aim for 120–160 characters. It does not directly rank your page, but a clear description can improve clicks.
Do meta keywords still matter?
Google does not use the keywords meta tag for ranking, but this generator includes it because some other tools and CMS platforms still show it. Focus first on title and description.
What are Open Graph tags?
Open Graph tags control how your page looks when shared on Facebook, WhatsApp and other platforms — its title, description and image.
